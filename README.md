# เปิดปุ๊บ ลุ้นปั๊บ — ซีคอนพลัส

เกมเปิดป้ายสะสมเหรียญ สำหรับจอทีวีแนวตั้ง 9:16 ที่เคาน์เตอร์
เปิดป้ายไปเรื่อยๆ จนกว่าจะกด "พอแล้ว" หรือเจอระเบิด **หนึ่งคนได้ 3 สิทธิ์**

ไฟล์เดียวจบ ไม่มี dependency ไม่ต้อง build รูปเหรียญฝังมาในไฟล์แล้ว

## ขึ้นเว็บ
GitHub → Vercel → Framework Preset เลือก **Other** → Build Command และ Output Directory เว้นว่าง

## กติกา
- แตะป้ายเพื่อเปิด เปิดต่อได้ไม่จำกัดจำนวนช่อง
- เจอระเบิด จบสิทธิ์นั้นทันที แต่เหรียญที่เก็บได้ยังเป็นของลูกค้า
- กด "พอแล้ว" ตอนไหนก็ได้
- ครบ 3 สิทธิ์แล้วสรุปยอดรวม แล้วเปลี่ยนผู้เล่น

## ตั้งค่า (ปุ่ม ⚙ มุมซ้ายบน)
สิทธิ์ต่อคน · จำนวนช่อง · ช่องเหรียญ · เหรียญต่อช่อง · ช่องระเบิด · กติกาตอนเจอระเบิด · เสียง

ด้านล่างมีแผงคำนวณโอกาสสดๆ บอกว่าสูตรที่ตั้งไว้จะแจกเหรียญเท่าไหร่ต่อ 100 คน

### ค่าเริ่มต้นตอนนี้ (9 ช่อง · เหรียญ 3 · ระเบิด 6 · 3 สิทธิ์)
| ตัวเลข | ค่า |
|---|---|
| สิทธิ์ที่ได้มือเปล่า | 67% |
| เหรียญเฉลี่ยต่อสิทธิ์ | 0.43 |
| เหรียญเฉลี่ยต่อคน | 1.29 |
| คนที่กลับบ้านมือเปล่าทั้ง 3 สิทธิ์ | 30% |
| เหรียญจ่ายต่อ 100 คน | 129 |

## คีย์ลัดสำหรับพนักงาน
`Space`/`Enter` เริ่มหรือไปสิทธิ์ถัดไป · `R` เริ่มผู้เล่นใหม่ · `Esc` กลับหน้าเชิญเล่น

## ยังไม่ได้ทำ
ระบบตัดพอยต์และการบังคับสิทธิ์อัตโนมัติ — ต้องมีฝั่งเซิร์ฟเวอร์และต้องเชื่อม API สมาชิกซีคอนพลัส
ตอนนี้ข้อความ "1 คน 3 สิทธิ์" เป็นการบอกลูกค้า ระบบยังไม่รู้จักตัวตนผู้เล่น พนักงานหน้าตู้เป็นคนดูแล
