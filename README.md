# Seacon Plus — เกมเปิดป้ายลุ้นรางวัล

เกมสำหรับจอทีวีแนวตั้ง 9:16 ที่ตั้งอยู่หน้าเคาน์เตอร์ ลูกค้าแตะเปิดป้ายทีละช่อง
เก็บของรางวัลไปเรื่อยๆ จนกว่าจะกด "พอแล้ว" หรือเจอระเบิด

ไม่เก็บข้อมูลผู้เล่น ไม่ต้องล็อกอิน ไม่มีเซิร์ฟเวอร์ สุ่มใหม่ทุกรอบ

---

## ทำไมเป็นไฟล์ HTML ไฟล์เดียว

ทั้งเกมอยู่ใน `index.html` ไฟล์เดียว ไม่มี build step ไม่มี dependency
สำหรับเครื่องที่ต้องเปิดค้างทั้งวันหน้างาน แบบนี้พังยากที่สุด และเวลาต้องแก้ด่วน
พนักงานคนไหนก็เปิดไฟล์แก้แล้ว push ได้เลย ไม่ต้องลง Node ไม่ต้องรอ build

## ขึ้น GitHub

```bash
cd seacon-game
git init
git add .
git commit -m "Seacon Plus flip game"
git branch -M main
git remote add origin https://github.com/<ชื่อบัญชี>/seacon-plus-game.git
git push -u origin main
```

## ขึ้น Vercel

1. เข้า vercel.com → **Add New** → **Project**
2. เลือก repo `seacon-plus-game`
3. Framework Preset เลือก **Other** — ช่อง Build Command กับ Output Directory เว้นว่างไว้
4. กด **Deploy**

ได้ URL มาประมาณ `https://seacon-plus-game.vercel.app` เอา URL นี้ไปเปิดบนทีวีได้เลย
หลังจากนี้ทุกครั้งที่ push ขึ้น main Vercel จะ deploy ใหม่ให้เองอัตโนมัติ

## ตั้งค่าเครื่องหน้างาน

- เปิดเบราว์เซอร์แบบเต็มจอ (กด `F11`) หรือรัน Chrome ด้วย
  `chrome --kiosk --incognito https://<url ของคุณ>`
- **ปิด screensaver และ sleep ของเครื่อง** ไม่งั้นจอดับกลางวัน
- **ต้องมีคนแตะจอครั้งแรกเสมอเสียงถึงจะดัง** เป็นกฎของเบราว์เซอร์ทุกตัว
  หน้า "แตะเพื่อเริ่ม" ทำหน้าที่ปลดล็อกเสียงให้อยู่แล้ว
- ถ้าไม่มีใครแตะจอ 2 นาที เกมจะกลับหน้าเชิญเล่นเอง

## ตั้งค่ากระดาน

กดไอคอน **⚙** มุมซ้ายบน แก้ได้เลยโดยไม่ต้อง deploy ใหม่:

| ค่า | ความหมาย |
|---|---|
| จำนวนช่องทั้งหมด | 9 หรือ 16 |
| ช่องที่เป็นเหรียญ | กี่ช่องบนกระดานที่ให้เหรียญ |
| ช่องเหรียญให้กี่เหรียญ | ปกติ 1 ถ้าใส่มากกว่านั้นจะขึ้นป้าย ×N |
| ช่องที่เป็นระเบิด | เจอแล้วจบรอบ |
| ช่องที่เหลือเป็น | ช่องว่าง หรือ รหัสรับของ 4 หลัก |
| เจอระเบิดแล้วเสียเหรียญทั้งหมด | สลับกติกาได้ |

ปุ่ม **เติมช่องที่เหลือด้วยระเบิดให้เต็ม** คือลัดสำหรับกระดานที่มีแต่เหรียญกับระเบิด

### แผงโอกาสได้เหรียญ

ใต้หน้าตั้งค่ามีเครื่องคำนวณให้ดูสดๆ ว่าสูตรที่ตั้งไว้จะได้ผลอย่างไร:

- **กลับบ้านมือเปล่า** กี่เปอร์เซ็นต์ของผู้เล่นที่ไม่ได้เหรียญเลย
- **เหรียญเฉลี่ยต่อคน**
- **เหรียญที่จ่ายต่อ 100 คน** — ตัวเลขนี้คืองบรางวัลที่ห้างจะถามหา
- แถบโอกาสได้ 1, 2, 3 เหรียญ

สูตรคณิตศาสตร์: สนใจแค่ลำดับของช่องเหรียญ (c) กับช่องระเบิด (b) เท่านั้น ช่องอื่นไม่มีผล

- โอกาสได้อย่างน้อย 1 เหรียญ = `c / (c + b)`
- เหรียญเฉลี่ยต่อรอบ = `c / (b + 1)`

## รูปเหรียญ

รูปเหรียญซีคอนพลัสถูกฝังลงใน `index.html` แล้วในรูปแบบ base64 (WebP 560px ~28 KB)
เกมจึงทำงานได้แม้เน็ตหลุด ไม่ต้องรอโหลดรูป

ไฟล์ต้นฉบับเก็บไว้เป็น `coin.png` และ `coin.webp` ในโฟลเดอร์นี้ เผื่อต้องเอาไปใช้ที่อื่น
ถ้าจะเปลี่ยนเหรียญใหม่ ส่งไฟล์มาได้เลย เดี๋ยวแปลงและฝังให้ใหม่
